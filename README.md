# N-Trip

> 여행이나 모임의 일정과 장소를 관리하고, 공동 지출을 자동으로 계산하여 최종 정산까지 지원하는 웹 서비스

<br>

## 프로젝트 개요

여행이나 모임에서는 여러 사람이 식비, 교통비, 숙박비 등의 비용을 나누어 결제하게 됩니다. 이 과정에서 누가 얼마를 지출했는지 기록하고, 참가자별 실제 부담 금액을 계산하여 최종적으로 누구에게 얼마를 보내야 하는지 정리하는 과정은 매우 번거롭습니다. 특히 해외여행의 경우 서로 다른 통화를 사용하기 때문에 환율을 적용하여 비용을 다시 계산해야 하는 불편함도 존재합니다.

**N-Trip**은 이러한 문제를 해결하기 위해 여행 및 모임의 지출 내역을 등록하고, 참가자별 부담 금액을 자동으로 계산합니다. 환율, 지도, 날씨 등의 외부 API를 활용하여 여행에 필요한 모든 정보를 하나의 서비스에서 편리하게 관리할 수 있습니다.

### 대상 사용자
* 가족, 친구 및 지인들과 여행을 계획하는 사용자
* 여러 명이 함께 비용을 부담하는 모임
* 해외여행에서 외화 지출을 정산해야 하는 사용자

<br>

## ✨ 주요 기능

### 1. 여행, 모임 및 일정 관리
* 여행 및 모임 생성, 참가자 초대 및 관리
* 여행 일정 및 장소 등록, 수정, 삭제 기능

### 2. 지출 및 자동 정산
* 지출 금액 입력 및 결제자 선택
* 개인별 총 지출액 및 실제 부담액 자동 정산
* 송금 횟수를 최소화하는 **정산 최소화 알고리즘** 적용
* 외화 지출 입력 및 실시간 원화 환산 기능

### 3. 통계 및 시각화
* 개인별 지출 통계 제공
* 여행/모임 전체 단체 비용 통계 시각화(그래프 및 차트)

<br>

## 🛠 기술 스택

| 분야 | 기술스택 | 활용 목적 |
| :--- | :--- | :--- |
| **Language** | Python 3 | 프론트엔드 및 백엔드 개발, API 연동 |
| **Frontend** | React | 웹 UI 개발 |
| **Backend** | FastAPI | REST API 서버 구현 |
| **Database** | PostgreSQL | 사용자, 일정, 지출, 정산 데이터 관리 |
| **Libraries** | Leaflet, OpenStreetMap | 지도 UI 구현 및 데이터 조회 |
| | FullCalendar | 여행 일정 및 캘린더 연동 |
| | Chart.js | 지출 통계 및 그래프 시각화 |
| **DevOps / Tools** | GitHub Actions, pytest, Docker | 자동화 테스트 및 CI/CD 환경 구축 |

## 협업 규칙

### 브랜치 전략 (GitHub Flow)
* `main` : 배포 가능한 안정 버전
* `feature/기능명` : 개별 기능 개발 브랜치

### 커밋 컨벤션
* `feat`: 새로운 기능 추가
* `fix`: 오류 수정
* `docs`: 문서 수정
* `refactor`: 코드 리팩토링
* `test`: 테스트 추가 및 수정
* `chore`: 기타 작업 (빌드 업무, 패키지 매니저 설정 등)

### PR 및 코드 리뷰
* 각 기능 개발 완료 후 Pull Request 생성
* 최소 1명 이상의 팀원 코드 리뷰 진행 후 `main` 브랜치에 병합
* 하나의 PR에 너무 많은 기능이 포함되지 않도록 단위 관리
